# Data Analysis Project – Python, ML & SQL  
_(Branch: Data_Analysis_Project)_

This repository contains a data analysis project combining **Python**, **machine learning (ML)** and **SQL** techniques. The aim is to showcase an end-to-end workflow: from data extraction and manipulation, through exploratory data analysis, to model building and evaluation.

---

## 🧪 Project Overview

- **Data extraction** using SQL queries and relational database management.  
- **Data cleaning** and preprocessing in Python (using e.g. pandas, numpy).  
- **Exploratory Data Analysis (EDA)**: visualizations, correlation studies, feature engineering.  
- **Machine Learning modelling**: regression/classification models, performance evaluation, hyper-parameter tuning.  
- **Integration** of results and reporting.
